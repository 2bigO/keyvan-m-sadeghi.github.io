Sigil

Keeping intent in the codebase

Long agentic coding sessions can lose the reasons behind earlier decisions. The code survives; the intent gets buried in conversation history. A later change can quietly undo work that mattered.

Sigil makes that intent a versioned artifact. .sigil files live alongside the implementation and describe component boundaries, behavior, and constraints. LLMs interpret local meaning; a deterministic kernel composes admitted claims and checks design coherence and implementation alignment.

Can explicit design intent help coding agents catch drift and avoid undoing earlier decisions?

That is the hypothesis we’re investigating at Qoherent, with a publication targeted for the end of 2026. The repository includes a benchmark with deliberately planted design and implementation problems. The paper is work in progress; the checks operate on admitted interpretations, so their conclusions depend on what those interpretations capture.
